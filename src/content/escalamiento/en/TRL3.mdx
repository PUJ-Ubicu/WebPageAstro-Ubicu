The Venturi-tube flow measurement system was designed, modeled and simulated based on standardized instrumentation recommendations. A patient-motivation system was designed, based on a videogame featuring an otter, to run on a mobile device. Communication was set up between the measurement device and the mobile device via Bluetooth, as well as from the mobile device to a patient administration and control program in the cloud.
